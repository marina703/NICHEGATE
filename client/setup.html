Etsy Connection

Auto-list products on the world's largest handmade marketplace

  1. Go to etsy.com/developers/register
  2. Click "Create a new app"
  3. App name: NicheGate
  4. Redirect URI: loading...
  5. Copy Keystring → paste into .env as ETSY_CLIENT_ID
  6. Copy Shared Secret → paste into .env as ETSY_CLIENT_SECRET
  7. Restart the server
⏳ Waiting — click Connect Etsy above when your Etsy app is approved
2

Gumroad Connection

Sell digital products directly to your audience

  1. Go to gumroad.com/settings/advanced
  2. Scroll to "Application Secrets"
  3. Click "Generate new application secret"
  4. Copy the token → paste into .env as GUMROAD_ACCESS_TOKEN
  5. Restart the server
⏳ Waiting for API key
3

Discord Notifications (Optional)

Get instant alerts for review day, trends, and sales

  1. In Discord, go to a server you admin
  2. Channel Settings → Integrations → Webhooks → New Webhook
  3. Copy webhook URL
  4. Run this in your project folder:
node -e "require('./server/database').db.prepare('UPDATE settings SET value = \"YOUR_WEBHOOK_URL\" WHERE key = \"webhook_url\"').run()"
